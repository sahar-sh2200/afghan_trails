# Afghan Trails — Interactive & Responsive Landing Page

A student landing-page project built with semantic HTML, external CSS, and vanilla JavaScript.

## Features
- Semantic page structure: header, navigation, main, sections, form, and footer.
- Responsive layout for mobile, tablet, and desktop.
- CSS Flexbox, Grid, Box Model, hover effects, and transitions.
- Working mobile hamburger menu.
- Working dark/light theme toggle.
- Contact form validation with inline error and success messages.
- Dynamic current year in the footer.

## Run locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts and remote Unsplash photos used in this demo.

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload all project files, keeping the folder structure.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL and test it on mobile and desktop.

## Important note
The contact form currently validates input in the browser and displays a success message. It does not send email or store messages on a server.
